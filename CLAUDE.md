# HRIS Indonesia — Selfie GPS Attendance

Proyek HRIS dengan metode approval-driven development (fase 0–18).

## Aturan kerja
- Baca `docs/PROGRESS.md` dulu untuk tahu fase terakhir dan statusnya.
- Kerjakan hanya fase yang sedang aktif; jangan lanjut sebelum user menulis APPROVE.
- Keputusan yang sudah disetujui ada di `docs/DECISIONS.md`; jangan dianalisis ulang.
- Setiap fase ditutup dengan format laporan approval (PROJECT / CURRENT PHASE / STATUS + 7 poin + pilihan A/B/C).
- Bahasa komunikasi: Bahasa Indonesia. Hemat token: tanpa log panjang, tanpa mencetak ulang source code.
- Dokumen `docs/*` dibuat bertahap sesuai fase, bukan sekaligus.
